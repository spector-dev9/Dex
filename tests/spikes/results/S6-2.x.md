# S6 — Contract suite on OpenCode 2.0.x

Date: 2026-10-23. Status: **blocked — no distributable 2.x artifact.**

## Checks

- GitHub Releases: latest is `v1.19.4`; no 2.x entry in the release
  list.
- Git tags `v2.0.32` and `v2.1.3` exist, but
  `/releases/tags/v2.0.32` and `/releases/tags/v2.1.3` return 404, so
  there are no release assets to run.
- npm `opencode-ai`: latest is `1.19.4`; no 2.x version.
- npm `opencode-linux-arm64`: latest is `1.19.4`; no 2.x version.
- The host has no Bun or Zig toolchain, so building the 2.x source tags
  locally is not a substitute for testing a release artifact.

## Decision

Keep the `1.19.3` pin. Do not claim 2.x contract compatibility until a
2.x runtime artifact is published. Re-run this check when GitHub
Releases or npm publishes 2.x; then run the Section 4.1 endpoint
inventory and the contract tests against its live `/doc`.

The drift fallback is implemented in `scripts/check-contract-drift.py`
and `.github/workflows/drift.yml`. A local run against the latest 1.19.4
release artifact reported 0 breaking findings and 0 warnings (162 paths,
same as 1.19.3); evidence is in
`results/raw/contract-drift-1.19.4.json`.

Raw evidence: `results/raw/s6-artifact-check.json`.
